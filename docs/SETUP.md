Owner: Jean. These commands operate only on the separate Bern checkout. J1 tests infrastructure, not the full archive application.

## Python environment

```bash
cd /home/pol/repos/bern-archives-20261018
export PATH="$HOME/.local/bin:$PATH"
uv sync --locked
uv run pytest -q
```

Only this checkout's `.venv` is changed. Do not install into Track 2A or change global Python/CUDA packages. The lock is generated by uv and committed; use `uv sync --locked` rather than upgrading packages ad hoc.

## Configure the H100

Copy `.env.example` to the ignored `.env` and set `BERN_HF_CACHE` to the existing cache, currently `/home/pol/repos/apertus-track2a-20261010/hf-direct`. This is a **read-only reuse of data**, not an import or modification of the robotics application. The helpers require the pinned revision and image; no image pull/model download is attempted.

```bash
uv run python -m scripts.serve_apertus start
uv run python -m scripts.serve_apertus status
uv run python -m core.health
# Exactly one bounded model connection test; choose a new output path per run:
uv run python -m core.health --generate --out runs/j1-smoke.json
```

The endpoint is `http://127.0.0.1:8010/v1`, with model `swiss-ai/Apertus-v1.5-8B`. The server uses BF16, context 8192, one sequence, eager mode and zero CPU offload. It reserves 40% of the H100 only after checking current free memory plus headroom. This is not a demonstrated ≤8 GB deployment.

Startup can take several minutes. The exact owned container/command is recorded in `runs/apertus-owner.json`, and startup logs are saved in `runs/apertus-server.log`. On startup failure, inspect only that recorded Bern container and its log; never stop all Docker containers or unrelated Python jobs. Successful setup leaves the Bern service running for subsequent work.

When finished, Jean can stop **only the recorded idle Bern service**:

```bash
uv run python -m scripts.serve_apertus stop
```

Stop refuses an ownership/configuration mismatch, an active request, or unknown idle status. No service-manager, cron job or driver changes are required.

## Private connection from another machine

```bash
ssh -N -L 8010:127.0.0.1:8010 pol@fond-filly.maas
```

Keep the tunnel terminal open; use a different local port if 8010 is occupied, and update only your local `.env`. The H100 model remains loopback-only. For the later Gradio UI, Jean can arrange a separate private UI tunnel rather than public sharing. Do not give the browser/UI model credentials or private raw data.
